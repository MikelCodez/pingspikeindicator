🚀 New Features & HUD Engine

  • Instant real-time delta spike detection algorithm using sliding-window latency samples.
  • In-Game Configuration screen with interactive click-and-drag positioning canvas.
  • Auto-snapping to corners and edges with live coordinate indicator.
  • 5 Dynamic accent themes: Ember Orange, Tactical Cyan, Toxic Lime, Void Purple, and Pure White.

⚡ Performance & Compatibility

  • Pure client-side implementation: zero outbound networking packets sent to the server.
  • 0.00% frame drop with pre-rendered font glyphs and cached batch buffers.
  • Strict clean architecture: pure Java records for config storage without runtime game class locks.
  • Multi-version branch backports for MC 1.20.1, 1.21.x, 1.21.11, and 26.x snapshots.
  • Tournament & competitive anti-cheat safe (Hypixel, Minemen, 2b2t).
